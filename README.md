<h1>Proyecto ForoHub</h1>

-Descripcion del proyecto:
Este proyecto realiza la simulacion de un foro donde se pueden registrar consultas sobre varios temas.

-Funcionamiento:
Al ejecutar la aplicacion deberas usar la herramienta de Insomnia para poder realizar las solicitudes, se cuenta con 
las siguientes opciones:

* Registrar topico: Esta opcion nos permite registar un topico en el foro.

* Listar topicos: Con esta funcion se muestran todos los topicos registrados en el foro.

* Actualizar topico: Esta opcion nos permite modificar un registro ya realizado anteriormente.

* Eliminar topico: Con esta opcion se realiza la eliminacion de un topico especifico, pero solo es a nivel logico
                    ya que todavia se mantiene en nuestra base de datos pero en modo inactivo.

 * Login usuario: En esta opcion se registra al usuario y a la vez nos genera un token que genera los permisos
                   que sera necesario para poder realizar las otras opciones mencionadas.
